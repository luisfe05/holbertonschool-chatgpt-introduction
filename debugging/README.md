# holbertonschool-chatgpt-introduction

## Description

This project focuses on debugging Python and HTML code samples using ChatGPT as a tool. The exercises involve identifying errors, fixing logic problems, handling invalid user input, improving game functionality, and documenting code. The goal is to develop the ability to use AI assistance effectively for debugging and code improvement tasks.

## Files

| File | Description |
|---|---|
| `factorial.py` | Fixes an infinite loop in a factorial calculator |
| `print_arguments.py` | Prints only the arguments passed to the script |
| `change_background.html` | Changes the background color when clicking the button |
| `mines.py` | Adds a win condition to the Minesweeper game |
| `factorial_recursive.py` | Adds documentation to the recursive factorial function |
| `checkbook.py` | Adds error handling for invalid user input |
| `tic.py` | Fixes Tic-Tac-Toe game logic and input validation |
